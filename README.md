# SmartCareerAssistant – AI-Based Career & Placement Preparation Android App

SmartCareerAssistant is a native Android application designed to help college students and fresh graduates prepare for placements, improve interview skills, build professional resumes, and receive AI-assisted career guidance.

The application combines Android development, Firebase services, resume generation, placement preparation modules, and Gemini-powered AI assistance into a centralized career preparation platform.

## Overview

The main goal of SmartCareerAssistant is to provide students with practical tools for career preparation in one Android application.

The application includes:

- Resume Builder
- AI Career Assistant
- Mock Interview
- Aptitude Practice
- Technical Skills Assessment
- DSA Challenge
- HR Interview Simulator
- Firebase-based authentication and user profile management

## Key Features

### 1. User Authentication

- User registration
- Login functionality
- Firebase Authentication
- User profile storage using Firebase Firestore
- Input validation
- Error handling

### 2. Professional Dashboard

The dashboard provides navigation to the major career preparation modules.

- Resume Builder
- Mock Interview
- AI Career Assistant
- Placement Preparation
- Logout functionality

### 3. Resume Builder

The Resume Builder allows users to create structured professional resumes.

Users can add:

- Personal information
- Email and phone number
- Location
- Professional profile links
- Career objective
- Education
- Skills
- Work experience
- Projects
- Achievements
- Languages

Additional functionality includes:

- Professional PDF resume generation
- Resume sharing

### 4. AI Career Assistant

The application integrates Gemini AI through Firebase AI Logic to provide AI-assisted career guidance.

Features include:

- Career guidance
- Skill improvement suggestions
- Interview preparation advice
- Career-related questions
- AI-generated responses
- Copy AI responses

### 5. Mock Interview

The Mock Interview module provides interview practice through structured questions.

Features include:

- Interview practice questions
- Multiple-choice answers
- Answer evaluation
- Score calculation
- Progress tracking
- Final interview result

### 6. Placement Preparation

The Placement Preparation module contains multiple assessment areas.

#### Aptitude Practice

- Multiple-choice aptitude questions
- Answer selection
- Score calculation
- Result display

#### Technical Skills Assessment

Currently focused on Java and Object-Oriented Programming concepts.

- Timed assessment
- Multiple-choice questions
- Question progress tracking
- Score calculation
- Final assessment result

#### DSA Challenge

Provides practice questions related to Data Structures and Algorithms.

Topics include:

- Arrays
- Stack
- Other DSA concepts

Features include:

- Difficulty labels
- Multiple-choice questions
- Score tracking
- Challenge completion result

#### HR Interview Simulator

The HR Interview Simulator allows users to practice role-specific HR interviews.

Users can select:

- Role
- Interview type
- Difficulty

The simulator provides:

- Six interview questions
- Text-based answer submission
- Basic answer evaluation using keywords and answer length
- Final feedback
- Score
